Star-Dancing Painting

A dancing painting where the stars respond to the frequency and beat of the music

Project Intent

The Star-Dancing Painting explores how engineering tools can amplify traditional art. I designed a layered canvas that responds to music and gestures, using microcontroller-driven LEDs to highlight the paint strokes in motion. The result is an interactive, glowing night-sky piece that feels alive even when standing still.

A real-time audio visualization system that captures sound through a microphone, performs frequency analysis using FFT, and maps the dominant frequency and volume to dynamic patterns on an LED matrix.

Overview

  • Audio sampled via analog microphone
  • FFT extracts dominant frequency
  • Frequency + volume mapped to LED position and brightness
  • Real-time LED response to music

Features

  • FFT-based frequency detection
  • 256-pixel LED mapping
  • Dynamic volume normalization
  • Adaptive calibration over time
  • Fail-safe LED shutdown
  • Multiple visualization modes

Hardware

  • Arduino Uno
  • Analog microphone module
  • WS2812B LED matrix (256 LEDs)
  • External power supply (recommended)

How It Works

1. Audio Sampling

  • Signal read from A0
  • Sampled at 2048 Hz
  • 128 samples per cycle

2. Frequency Analysis

  • FFT converts signal to frequency domain
  • Dominant frequency extracted

3. Normalization

  • Tracks min/max frequency and volume
  • Auto-adjusts sensitivity over time

4. LED Mapping

Running the Project

  1. Install libraries
  2. Upload code to Arduino
  3. Open Serial Monitor (9600 baud)
  4. Play music near microphone
  5. Observe LED response

Notes

  • FFT resolution limited by Arduino Uno
  • External power recommended for LEDs
  • Auto-calibration adjusts to environment
